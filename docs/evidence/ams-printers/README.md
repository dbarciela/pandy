# AMS and printer demo evidence

The numbered images (the full 200-configuration matrix, kept out of git because of its size) show the Devices screen on the compatible Android phone, using demo data. Each filename gives the printer model, AMS count and AMS type. The matrix was captured before the final HT slot-width refinement and mixed-HT demo option; those later changes do not alter the matrix configurations shown. These images exercise the demo, not physical printer compatibility.

The H2D images show the final build with four AMS 2 Pro units and eight additional AMS HT units. The Filament image shows two loaded slots and the corrected single-slot HT layout. The configuration image shows the demo selector. Status bars were cropped before saving.

See [ios-check.md](ios-check.md) for the Mac simulator check.
